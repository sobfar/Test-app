# Board Setup App

اپی که لیست وای‌فای‌های اطراف رو نشون میده، با تپ کاربر به وای‌فای برد وصل می‌شه و صفحه تنظیمات برد (`192.168.4.1`) رو داخل خود اپ باز می‌کنه.

## ساخت APK با گیت‌هاب (بدون نیاز به کامپیوتر)

1. یک ریپازیتوری جدید بساز: [github.com/new](https://github.com/new)
2. توی صفحه‌ی ریپازیتوری، **Add file → Upload files** رو بزن و همه‌ی فایل‌ها و پوشه‌های زیپ (از جمله پوشه‌ی مخفی `.github`) رو آپلود و Commit کن.
3. برو تب **Actions**؛ اجرا حدود ۵ تا ۱۰ دقیقه طول می‌کشه.
4. وقتی ✅ سبز شد، پایین همون اجرا از بخش **Artifacts** فایل `board-setup-app-debug-apk` رو دانلود کن (یه zip حاوی `app-debug.apk`)، با یه فایل‌منیجر بازش کن و نصبش کن (نیاز به «نصب از منابع ناشناس» داره).

## ساختار پروژه
فقط یک فایل سورس داری که ویرایشش می‌کنی: **`app.html`** — شامل HTML، استایل (`<style>`) و منطق اپ (`<script type="module">`) با هم. هر تغییری خواستی بدی، همینو ویرایش کن و دوباره آپلودش کن (کافیه فقط همین یه فایل رو overwrite کنی، نیازی به فایل‌های دیگه نیست).

بقیه‌ی فایل‌ها رو دست نزن (خودکار و پیکربندی هستن):
- `scripts/build.js` — چون `app.html` از پلاگین‌های واقعی (`import`) استفاده می‌کنه که مرورگر نمی‌تونه مستقیم اجراشون کنه، این اسکریپت (با esbuild) کدش رو باندل می‌کنه و `www/index.html` نهایی رو می‌سازه. گیت‌هاب اکشن خودش با دستور `npm run build` این کارو انجام می‌ده.
- `package.json`, `capacitor.config.json`, `network_security_config.xml`, `.github/workflows/build.yml` — پیکربندی ساخت APK.

## جریان کار اپ
1. لیست وای‌فای‌های اطراف نشون داده می‌شه (نیاز به مجوز موقعیت مکانی).
2. با تپ روی وای‌فای برد، رمز وارد می‌شه و با `autoRouteTraffic: true` وصل می‌شه (چون برد اینترنت نداره، ترافیک اپ باید مستقیم از همون شبکه رد بشه).
3. از صفحه‌ی «تنظیمات برد» می‌شه صفحه‌ی `192.168.4.1` رو باز کرد و سعی کرد فیلدهای کالیبراسیون رو خودکار پر کرد.

## پر کردن خودکار فیلدهای برد
مقادیر کالیبراسیون از دکمه‌ی ⚙️ قابل ویرایش و ذخیره‌ست. چون ساختار دقیق HTML صفحه‌ی برد معلوم نیست، اسکریپت پرکردن با چند کلیدواژه‌ی فارسی/انگلیسی رایج حدس می‌زنه. وقتی به برد دسترسی داشتی:
1. دکمه‌ی «استخراج HTML» رو بزن.
2. خروجی رو کپی کن و بفرست.
3. با دیدن ساختار واقعی، تابع `buildFillScript` در `app.html` رو دقیق می‌کنم.

## نکات مهم
- پلاگین‌ها: [`@capgo/capacitor-wifi`](https://github.com/Cap-go/capacitor-wifi) و [`@capgo/capacitor-inappbrowser`](https://github.com/Cap-go/capacitor-inappbrowser) — هر دو رایگان و متن‌باز.
- اگه IP برد چیزی غیر از `192.168.4.1` بود، مقدار `BOARD_URL` رو در `app.html` عوض کن.
- اگه رمز وای‌فای برد ذخیره‌ست و باز هم وصل نمی‌شه، رمز رو خالی نذار — بعضی بردها اتصال باز (بدون رمز) رو قبول نمی‌کنن.
